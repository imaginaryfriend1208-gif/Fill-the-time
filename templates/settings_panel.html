How to create a prompt preset

Edit the System and User prompts below, keep {{previousSummary}} and {{content}} in the User prompt, then choose Save New. Update overwrites the selected preset; Export and Import share presets as JSON.

Summarization Prompts

Merge Prompt (final rolling summary)

Combines the previous summary with new events into the final chapter. Macros: {{previousSummary}}, {{content}}, {{worldInfo}} (constant lorebook entries) and card macros like {{description}}, {{personality}}, {{mesExamples}}.

Chunk Prompt (per-chunk digests & stocking)

Condenses each chunk (including background stocking) before the merge. When off, the Merge Prompt is used with an empty {{previousSummary}}. Macros: {{content}}, {{worldInfo}}.
